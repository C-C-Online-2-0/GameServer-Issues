# GameServer Issues

Public bug reports and feature requests for the **C&C Online game servers**, the online services behind multiplayer for the supported games.

Supported games: Red Alert 3, Tiberium Wars, Kane's Wrath, The Battle for Middle-earth, The Battle for Middle-earth II, and The Rise of the Witch-king.

## What this repository is

- The public issue tracker for the game servers: login, lobbies, chat, friends, hosting and joining games, and connection problems.
- The place to report server bugs and outages, and to suggest new features or improvements to the online services.

## What this repository is not

- **Not the source code.** The game servers are closed source. This repository contains no server code and does not accept code contributions.
- **Not for the Tacitus client.** Problems with installing, updating, or using Tacitus itself belong in [Tacitus-Issues](https://github.com/C-C-Online-2-0/Tacitus-Issues).
- **Not a support desk.** For general help, setup questions, or account recovery, ask in the [C&C Online Discord](https://discord.cnc-online.net).
- **Not for security reports.** Never post vulnerabilities, exploits, or cheats publicly. Follow the [security policy](.github/SECURITY.md) instead.
- **Not for player reports or game balance.** Reports about other players and balance discussions belong on Discord.

## Before opening an issue

- Search existing issues (including closed ones) to avoid duplicates.
- Check the C&C Online Discord for announcements about known outages or maintenance.
- Use the bug report or feature request form so the team has what it needs to triage.
- Do not include passwords, tokens, email addresses, IP addresses, or other personal data, including in attached logs and screenshots.

Issues are reviewed and triaged by the C&C Online team. Opening an issue does not guarantee that it will be implemented or fixed by a certain date.

## Pull requests

Because the code is private, pull requests cannot be reviewed or merged. They are closed automatically. Please open an issue instead.
